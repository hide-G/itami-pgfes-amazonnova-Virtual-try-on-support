# Webカメラ撮影アプリ

## 概要
ブラウザでWebカメラを使用して写真を撮影し、PNG、JPEG、WebP形式で保存できるWebアプリケーションです。

## 機能
- 📸 Webカメラからのリアルタイムプレビュー
- 🖼️ PNG、JPEG、WebP形式での画像保存
- 💾 撮影した画像のダウンロード機能
- 📱 レスポンシブデザイン（PC・スマートフォン対応）

## 使い方

### 1. アプリケーションの起動
`index.html` ファイルをブラウザで開きます。

### 2. カメラへのアクセス許可
ブラウザがカメラへのアクセス許可を求めてきた場合は、「許可」をクリックしてください。

### 3. 画像の撮影
1. カメラプレビューで構図を確認
2. 保存形式を選択（PNG、JPEG、WebP）
3. 「📸 撮影」ボタンをクリック

### 4. 画像のダウンロード
撮影した画像が右側に表示されたら、「💾 画像をダウンロード」ボタンをクリックして保存できます。

## 画像形式の特徴

### PNG（推奨）
- **メリット**: 画質の劣化がない、透過情報を保持可能
- **デメリット**: ファイルサイズが大きい
- **用途**: 高品質な画像が必要な場合、後で編集する予定がある場合

### JPEG
- **メリット**: ファイルサイズが小さい、幅広い対応
- **デメリット**: 圧縮による画質劣化
- **用途**: Web公開用、メール添付用

### WebP
- **メリット**: JPEGより高圧縮率、高画質
- **デメリット**: 一部の古いブラウザでは非対応
- **用途**: 最新のWeb環境での使用

## 技術仕様

### 使用技術
- HTML5
- CSS3（Grid Layout、Flexbox）
- JavaScript（ES6+）
- Web APIs:
  - MediaDevices.getUserMedia()
  - Canvas API
  - Blob API

### ブラウザ対応
- Chrome 53+
- Firefox 36+
- Safari 11+
- Edge 12+

### セキュリティ
- HTTPS環境での実行を推奨（一部のブラウザではHTTPSが必須）
- カメラアクセスはユーザーの明示的な許可が必要

## トラブルシューティング

### カメラが起動しない場合
1. ブラウザの設定でカメラへのアクセスが許可されているか確認
2. 他のアプリケーションがカメラを使用していないか確認
3. HTTPS環境で実行しているか確認

### 画像がダウンロードできない場合
1. ブラウザのポップアップブロックを無効化
2. ダウンロードフォルダの権限を確認

## カスタマイズ

### カメラの切り替え
`script.js` の以下の部分を変更することで、フロントカメラとバックカメラを切り替えられます：

```javascript
// フロントカメラ（デフォルト）
facingMode: 'user'

// バックカメラ（モバイル向け）
facingMode: 'environment'
```

### 画質の調整
JPEG形式の画質は以下の部分で調整できます（0.0〜1.0）：

```javascript
canvas.toDataURL('image/jpeg', 0.9) // 90%の品質
```
